## Android

### 连接
- [ ] 标准内核：首次连接弹出系统 VPN 授权，同意后状态变为「已连接」，通知栏出现常驻通知
- [ ] 标准内核：打开任意网站 / 应用能正常上网，首页出口 IP 与节点地区一致
- [ ] 兼容内核：设置 › 内核与资源切到「兼容内核」，重新连接成功，节点组与延迟正常显示
- [ ] 兼容内核：切换节点、测速、断开 / 再连接都正常
- [ ] 两种内核来回切换后，订阅、节点选择、分流设置都保持不变
- [ ] 快捷设置磁贴、通知栏「断开」按钮能连接 / 断开

### 断网重连
- [ ] 连接中开启飞行模式 10 秒再关闭，网络恢复后自动恢复可用（不需手动重连）
- [ ] Wi-Fi 与移动数据来回切换，连接自动恢复，无长时间断网
- [ ] 两种内核都测一遍上面两项

### 杀后台恢复
- [ ] 连接中从最近任务划掉穿云，VPN 仍保持连接
- [ ] 在系统设置里「强行停止」后，再打开穿云状态正确（显示未连接，能重新连接）
- [ ] 兼容内核进程被系统结束（可用开发者选项「不保留活动」或内存压力）后自动恢复连接
- [ ] 重启手机后，开启「开机自启」时自动连接；关闭时不连接

### 分应用代理
- [ ] 「只代理所选应用」模式：名单内应用走代理，名单外直连
- [ ] 「绕过所选应用」模式：名单内应用直连，其余走代理
- [ ] 修改名单后重新连接即生效；两种内核结果一致

### 活动页
- [ ] 活动页连接 / 日志 / DNS 三个标签数据正常刷新
- [ ] 切换到其他标签后，原标签的数据流停止（诊断日志里不再有对应订阅；耗电无明显变化）
- [ ] 离开活动页或切到后台后，所有数据流停止；回到页面后重新开始
- [ ] 连接列表能关闭单条连接、能搜索

### DNS 页
- [ ] DNS 标签显示域名、解析结果、耗时、是否缓存命中
- [ ] 国内域名走国内 DNS、国外域名走远程 DNS，结果符合分流设置
- [ ] 「恢复推荐 DNS」后设置还原且连接正常

- [ ] 「自动连接」页：自动运行、按需运行、每天定时连接 / 断开都能保存并生效
- [ ] 「后台保活」页：自启动、允许后台运行、不在最近任务显示三项都能跳转 / 生效，且只出现一次

- [ ] 设置搜索：用旧名称（如「同步与备份」「资源」「自启动」）搜索能找到并跳到新位置
