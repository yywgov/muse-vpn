# 穿云界面术语表（1.22.0 起）

界面统一用左列的词；右列的旧叫法只留在设置搜索的关键词里（搜旧名照样找得到）。只改界面文案，存储键、偏好名、内核配置字段都不变。代码里的常量在 `lib/features/muse/logic/terms.dart`。

| 统一用词 | 旧叫法 / 说明 |
|---|---|
| 分组 | 代理组、策略组（订阅里的 selector / urltest 等节点集合） |
| 分流模式（规则 / 全局） | 模式、规则 / 全局模式、代理模式 |
| 接管方式（TUN / 系统代理，Windows） | 运行模式、网络接管 |
| 首页风格 | 首页样式（「模式」不再指它） |
| 订阅修改 | 覆写、订阅覆写、全部覆写、本地覆写 |
| 交给 | 出站（连接详情「为什么走这条」） |
| 来自 | 入站（连接详情） |
| 经过 | 链路（连接详情） |
| 测延迟 | 测速（延迟测试按钮：首页、节点页、多选、托盘、诊断） |
| 测网速 | 下载测速 |
| 流量（底栏）：连接 / 规则 | 设置 › 活动、设置 › 分流规则 |
| 自动化 | 启动与断线、自动连接 |

协议名（VLESS、VMess、Trojan、Shadowsocks、Hysteria2 等）不翻译。

## 底栏与设置结构（1.22.0）

- 底栏 / 侧栏：首页 / 节点 / 流量 / 设置。
- 流量：顶部「连接 / 规则」。连接 = 实时 / 日志 / DNS / 统计；规则 = 分流模式、我的规则、规则来源、规则测试。
- 设置一级 6 组：连接与网络（网络、内核与资源、隐私与通知）、订阅与节点（订阅列表、订阅设置、节点设置、订阅修改）、外观、自动化、诊断、关于（关于穿云、备份与恢复、开发者选项）。
